# 人工智能学院双创平台

面向校内师生的大学生创新创业项目协作平台。学生和老师填写项目想法、双向表达合作意向、组队做项目，答辩意见统一归档。

---

## 一、这是什么

一个**校内**的双创项目协作平台（不是校企对接平台）。

**三端角色：**

- **学生**：填写自己的项目想法，浏览别人的内容并「感兴趣」，申请加入；
  通过后自动开通沟通渠道，可以组队做项目
- **老师**：可以填写项目想法（带「老师发布」标识），也可以对学生的内容表达兴趣、
  带学生做项目
- **管理员**：审核注册账号和发布内容，上传答辩意见，管理小组，看数据看板

**核心业务链路：**

```
填写内容 → 管理员审核 → 双方浏览 → 对别人内容「感兴趣」→ 发布者处理
                                        ↓ 通过
                         自动开临时沟通通道 + 可建长期会话 → 组队做项目
                                        ↓
                            答辩意见归档（管理员上传，组长设可见范围）
```

平台是**审核制**：注册要审核，填写的内容要审核，通过才公开可见。

---

## 二、和原平台的区别

这个项目是从一个「校企产学研对接平台」改造来的，主要改动：

| 项 | 原来 | 现在 |
|---|---|---|
| 定位 | 校企对接 | **校内双创协作** |
| 角色 | 学生 / 企业 / 管理员 | **学生 / 老师 / 管理员**（企业端已移除） |
| 核心动作 | 「发布」项目 / 需求 | 「**填写**」项目想法 |
| 组织方式 | 个人对个人 | **小组制**（一个小组一个项目，组长负责） |
| 答辩意见 | 无 | **管理员上传 + 两层可见性控制** |
| 沟通方式 | 只有站内会话 | **临时通道（免登录、有期限）+ 长期会话** |

> 企业端相关的代码、数据库表和角色记录**已全部移除**，不是隐藏而是删掉了。

## 五、5 分钟跑起来

### 1. 建数据库

```bash
mysql -uroot -p < ai-collab-hub-server/sql/ai_collab_hub.sql
```

执行完会自动建库 `ai_collab_hub`、建全部 29 张表、写入初始字典数据和管理员账号。

### 2. 改配置

改 `ai-collab-hub-server/ai-collab-admin/src/main/resources/application.yaml`，
把数据库密码、Redis 地址改成你自己的。

### 3. 起后端

```bash
cd ai-collab-hub-server
mvn clean package -DskipTests
java -jar ai-collab-admin/target/AiCollabHub.jar
```

后端跑在 **28848** 端口。

### 4. 起前端

```bash
cd ai-collab-hub-web
npm install
npm run dev
```

前端跑在 **3000** 端口，浏览器打开 http://localhost:3000

## 六、注意事项

1. **找回密码靠手机号** —— 手机号在注册时是必填的，就是为了保证每个账号都能找回密码
2. **密码强度**：至少 8 位，须含大小写字母 + 数字 + 特殊字符
3. **上传目录**：默认在运行目录下的 `WebFile/`，生产环境建议配 Nginx 静态映射
4. **Redis 用的是 database 1**，别和别的项目冲突
5. **视频功能未启用**：字段已预留（`video_url` / `video_cover`），当前版本不做
