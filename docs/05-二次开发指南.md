# 二次开发指南

这份文档给后面接手的人看：怎么加功能、代码写在哪、有哪些坑。

---

## 一、加一个功能要改哪些地方

以「加一个『项目报名人数统计』」为例，标准流程：

```
1. 数据库     sql/ai_collab_hub.sql 加字段或加表
2. 实体类     ai-collab-xxx/models/po/ 加字段
3. Mapper     ai-collab-xxx/mapper/ 加方法（简单查询用 BaseMapper 自带）
4. DTO/VO     models/dto/ 加入参，models/vo/ 加出参
5. Service    接口 + 实现，业务逻辑写这里
6. Controller ai-collab-admin/openapi/ 加接口方法
7. 前端 api   src/api/xxx.js 加请求方法
8. 前端页面   src/views/ 加或改页面
9. 文档       更新 03-功能清单与改动说明.md
```

## 二、后端开发规范

### 2.1 包结构

```
com.qll.ucch.
├── models/
│   ├── po/          实体类（跟数据库表一一对应）
│   ├── dto/         入参（前端传来的）
│   ├── vo/          出参（返回给前端的）
│   └── enums/       枚举
├── mapper/          数据库操作接口
├── service/         业务接口
├── service/impl/    业务实现
├── handler/         处理器
├── utils/           工具类
├── constance/       常量
└── exception/       异常
```

**为什么要分 po / dto / vo？**
- `po` 是数据库表结构，别直接返回给前端（会泄露密码等敏感字段）
- `dto` 只接收前端该传的字段，配合 `@Valid` 做校验
- `vo` 只返回前端该看的字段

### 2.2 实体类写法

```java
@Data
@TableName("blog_article_info")
public class BlogArticleInfo {

    @TableId(type = IdType.ASSIGN_ID)
    private Long id;

    @TableField("user_id")
    private Long userId;

    // 逻辑删除字段，MyBatis-Plus 自动处理
    @TableLogic(value = "null", delval = "now()")
    private LocalDateTime deleteTime;
}
```

**注意**：
- 主键用 `IdType.ASSIGN_ID`（雪花算法），别用自增
- 有 `create_time` / `update_time` / `create_by` / `update_by` 的继承 `BasePo`，会自动填充

### 2.3 Service 写法

```java
@Service
@RequiredArgsConstructor
public class BlogArticleServiceImpl implements IBlogArticleService {

    private final BlogArticleInfoMapper articleMapper;

    @Override
    public Long publishArticle(ArticleSaveDTO dto, Long currentUserId) {
        // 1. 参数和业务规则校验
        if (StringUtils.isBlank(dto.getTitle())) {
            throw new BusinessException("标题不能为空");
        }

        // 2. 组装实体
        BlogArticleInfo po = new BlogArticleInfo();
        po.setUserId(currentUserId);
        po.setTitle(dto.getTitle());
        po.setStatusId(1);   // 1 = 待审核

        // 3. 落库
        articleMapper.insert(po);

        // 4. 返回
        return po.getId();
    }
}
```

**注意**：
- 用构造器注入（`@RequiredArgsConstructor` + `final`），别用 `@Autowired` 字段注入
- 校验失败直接 `throw new BusinessException("提示")`，全局异常处理器会转成统一返回
- 要当前登录用户ID，从 Controller 传进来（Service 不直接依赖 SecurityContext，方便单测）

### 2.4 Controller 写法

```java
@RestController
@RequestMapping("/blog/article")
@RequiredArgsConstructor
@Tag(name = "文章管理")
public class BlogArticleController {

    private final IBlogArticleService articleService;

    @PostMapping
    @Operation(summary = "发布内容")
    public Result<Long> publish(@Valid @RequestBody ArticleSaveDTO dto) {
        Long id = articleService.publishArticle(dto, SecurityContext.getUserId());
        return Result.success("发布成功，等待审核", id);
    }
}
```

**注意**：
- 需要登录的接口不用管，拦截器自动校验
- 免登录接口加 `@IgnoreAuth` 注解
- 每个接口都加 `@Operation(summary="中文说明")`，Knife4j 文档才好看

### 2.5 加免登录接口

在 `WebSecurityConfig` 的 `WHITE_LIST` 数组里加路径：

```java
private static final String[] WHITE_LIST = {
    "/user/login/**",
    // 你新加的
    "/your/path/**",
};
```

### 2.6 加新模块

1. 建目录 `ai-collab-xxx/`
2. 写 `pom.xml`（parent 指向 `ai-collab-hub`）
3. 在父 pom 的 `<modules>` 里加一行
4. 谁要用就在谁的 pom 里加依赖

## 三、前端开发规范

### 3.1 加一个接口

在 `src/api/` 对应文件里加：

```javascript
export function yourFunction(params) {
  return request({
    url: '/your/path',
    method: 'get',   // get/post/put/delete
    params           // get 用 params，post/put 用 data
  })
}
```

### 3.2 加一个页面

1. 在 `src/views/` 建 `.vue` 文件
2. 在 `src/router/index.js` 注册路由

```javascript
{
  path: 'your-page',
  name: 'YourPage',
  component: () => import('@/views/cooperation/YourPage.vue'),
  meta: { title: '页面标题' }
}
```

**注意**：路由用懒加载（`() => import(...)`），不然首屏包会很大。

### 3.3 取当前登录用户

```javascript
import { getUserInfo, getRoleCode, getRoleId, isAdmin } from '@/utils/authSession'

const user = getUserInfo()      // { id, nickname, avatar, roleCode, ... }
const role = getRoleCode()      // 'STUDENT' / 'TEACHER' / 'ADMIN'
```

### 3.4 状态转中文

统一用 `src/utils/roleDisplay.js`，别在页面里自己写 map：

```javascript
import {
  auditStatusName, articleStatusName, collabProgressName,
  roleName, noticeTypeName
} from '@/utils/roleDisplay'

articleStatusName(2)  // '已发布'
```

要加新的状态映射，改这个文件，别散落在各页面。

### 3.5 上传文件

```javascript
const formData = new FormData()
formData.append('file', file)
await request({
  url: '/your/upload',
  method: 'post',
  data: formData,
  headers: { 'Content-Type': 'multipart/form-data' }
})
```

上传组件要带 token（`el-upload` 不走 axios 拦截器）：

```javascript
const uploadHeaders = computed(() => {
  const headerName = 'Authorization'
  return { [headerName]: 'Bearer ' + getToken() }
})
```

### 3.6 主题色

全局样式在 `src/assets/css/global.css`，主题色定义在 `:root`：

```css
--ai-primary: #1d3a6b;       /* 主色 深蓝 */
--ai-gold: #c9a227;          /* 辅色 金 */
```

改主题只改这里，页面里都引用变量。

## 四、常见开发任务

### 4.1 加一张表

1. 在 `sql/ai_collab_hub.sql` 末尾加 `CREATE TABLE`
2. 建实体类（`@TableName` 指向表名）
3. 建 Mapper（`extends BaseMapper<实体>`，加 `@Mapper`）
4. 写 Service

### 4.2 加一个字典

字典表都在 `blog_type` / `blog_article_status` / `blog_progress` / `blog_article_tag`。

加新类型：改 `blog_type` 表数据 + `ArticleTypeEnum` 枚举 + 前端 `roleDisplay.js`。

### 4.3 加一个消息通知

```java
// 注入通知服务
private final INoticeService noticeService;

// 发消息（用户ID、标题、内容、类型）
noticeService.sendNotice(
    targetUserId,
    "审核通过",
    "你发布的《xxx》已通过审核，现已上线。",
    1   // 1=审核结果 2=收到申请 3=系统通知 4=会话消息
);
```

### 4.4 加一个新角色

1. `sys_role` 表加一行
2. `CommonConst` 加角色ID和标识常量
3. `sys_user_review` 的审核逻辑要认这个角色
4. 前端 `roleDisplay.js` 加映射
5. 路由守卫按需调整

## 五、坑（踩过的）

### 5.1 打包时的依赖顺序

Maven 多模块有依赖顺序，改完公共模块（common）后最好整个项目重新 `mvn clean install`，
不然可能出现「改了 common 但其他模块还是老的」的情况。

### 5.2 MyBatis-Plus 逻辑删除

表有 `delete_time` 字段 + 实体标 `@TableLogic` 后：
- `mapper.deleteById(id)` 会自动变成 `UPDATE ... SET delete_time = now()`
- 查询自动过滤 `delete_time IS NULL`

**自定义 SQL 要自己加 `delete_time IS NULL` 条件**，插件管不到手写的 SQL。

### 5.3 分页插件

`MybatisPlusConfig` 里必须注册 `PaginationInnerInterceptor`，不然 `Page` 查询不生效（返回全部数据）。

### 5.4 拦截器白名单

新加免登录接口忘了加白名单，会一直返回 401。加完别忘了重启。

### 5.5 前端 v-model 绑定对象属性

Element Plus 表单校验要 `prop` 和 `model` 对得上：

```vue
<el-form :model="form" :rules="rules">
  <el-form-item prop="title">        <!-- prop 里写属性名 -->
    <el-input v-model="form.title" /> <!-- v-model 要能取到 -->
  </el-form-item>
</el-form>
```

### 5.6 路由刷新 404

前端用 history 模式，Nginx 必须配：
```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

### 5.7 上传大文件

Nginx 默认限制 1MB，改了 `client_max_body_size`；
Spring Boot 的 `spring.servlet.multipart.max-file-size` 也要改。

## 六、可以继续做的方向

### 6.1 站内会话改 WebSocket

现在 `ChatCenter.vue` 是 15 秒轮询，能用但不是实时。

改法：
1. 后端加 `spring-boot-starter-websocket` 依赖
2. 写 `WebSocketConfig` + `ChatWebSocketHandler`
3. 前端用 WebSocket API 替换轮询

### 6.2 邮件通知

表和接口都有（`sys_email_config` + `SysEmailConfigService`），差业务触发点。

在 `BlogArticleServiceImpl.auditArticle()` 审核通过后，查收件人邮箱发信即可。

### 6.3 导出 Excel

用 EasyExcel 或 Apache POI：
1. 后端加导出接口，返回文件流
2. 前端 `blob` 方式接收并下载

`request.js` 已经处理了 blob 响应（不剥壳）。

### 6.4 内容过期自动下架

写个定时任务：

```java
@Component
@EnableScheduling
public class ArticleExpireTask {

    @Scheduled(cron = "0 0 2 * * ?")   // 每天凌晨 2 点
    public void offlineExpired() {
        // 查 expected_deadline < 今天 且 status_id = 2 的内容，改成 4（已下架）
    }
}
```

### 6.5 移动端适配

现有页面用了 Element Plus 的栅格（`el-row` + `el-col` 的 `:xs/:sm/:md`），
基本框架在，主要是细节间距和表格在窄屏的处理。
