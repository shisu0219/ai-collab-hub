## 快速开始

```bash
# 1. 建数据库（建库 + 建表 + 初始数据）
mysql -uroot -p < ai-collab-hub-server/sql/ai_collab_hub.sql

# 2. 起后端（默认 28848 端口）
cd ai-collab-hub-server
mvn clean package -DskipTests
java -jar ai-collab-admin/target/AiCollabHub.jar

# 3. 起前端（默认 3000 端口）
cd ai-collab-hub-web
npm install
npm run dev
```

浏览器打开 http://localhost:3000

**测试账号**：

建库脚本只预置了**管理员**账号：

| 账号 | 密码 | 角色 |
|---|---|---|
| admin | `ChangeMe@123`（首次登录后请立刻修改） | 管理员 |

学生和老师账号请通过前端注册页自行创建，注册后需管理员在后台审核通过才能登录。

**登录时先选身份**（学生 / 老师 / 管理员），选错入口登不进去。

## 功能概览

### 三种角色

| 角色 | 能做什么 |
|---|---|
| 学生 | 填写项目想法、浏览、**对别人的内容表达兴趣**、我的申请、我的小组、答辩意见、站内沟通、临时通道、消息中心、收藏 |
| 老师 | 同上 + **可填写项目想法**（发的内容带「老师发布」标签） |
| 管理员 | 账号审核、内容审核、小组管理、答辩意见管理、数据看板、消息、操作日志 |

> 「发布」在平台上叫「**填写**」—— 双向的，谁都可以填想法。

### 核心流程

```
注册 → 管理员审核 → 登录
  ↓
填写内容 → 管理员审核 → 公开可见
  ↓
双方浏览 → 对别人内容「感兴趣」→ 发布者处理
  ↓ 通过
自动开临时沟通通道 + 可建长期会话
  ↓
组队做项目 → 管理员上传答辩意见 → 组长设可见范围
```

### 两种沟通方式

| | 临时通道 | 站内会话（长期） |
|---|---|---|
| 怎么进 | 凭链接，**免登录可看** | 要登录，在会话列表里 |
| 有期限 | 有（默认 72 小时） | 无 |
| 谁能发言 | 只有双方（外部人可看不可发） | 只有双方 |

### 主要页面

**前台（学生/老师）**
- 浏览合作（搜索 + 多条件筛选，「老师发布」有标签）
- 填写项目想法
- 我的发布
- 我的申请（我发出的 / 我收到的）
- **我的小组**（组长可管成员、设答辩意见可见范围）
- 站内沟通（长期会话）
- 临时通道（免登录页）
- 消息中心（分类 + 搜索）
- 我的收藏
- 内容详情（含答辩意见区）
- 个人主页 / 个人中心

**后台（管理员）**
- 数据看板（角色分布按 学生/老师/管理员 三档）
- 账户审核（支持批量）
- 内容管理（支持批量）
- **小组管理**
- **答辩意见管理**（上传、编辑、逐条设可见性）
- 账户管理
- 标签管理
- 操作日志

## 本次改动重点

在原「校企产学研对接平台」基础上改造为**校内双创协作平台**：

| 改进 | 解决的问题 |
|---|---|
| **角色改三端** | 企业端移除，改为 学生 / 老师 / 管理员 |
| **「发布」→「填写」** | 双向的，老师也能填想法 |
| **小组制** | 一个小组一个项目，组长负责，答辩意见挂靠小组 |
| **答辩意见** | 管理员上传 + 两层可见性（全局默认 + 单条覆盖） |
| **临时沟通通道** | 免登录、有期限，申请通过自动开 |
| **站内会话** | 原来对接通过后就断了，只能线下加微信 |
| **老师也能填内容** | 老师发的内容带「老师发布」标识 |
| **申请表单按角色分** | 学生填年级班级擅长；老师填为什么感兴趣 + 联系方式 |
| **找回密码改手机号** | 手机随身带，比邮箱可靠 |
| **红点联动已读** | 消息中心和站内沟通的未读数同步 |
| **附件白名单扩容** | 原来 doc/docx/xls/ppt/zip 全传不了 |
| **搜索与筛选 / 批量审核 / 拒绝理由模板 / 对接进度流转 / 数据看板 / 收藏 / 操作日志** | 原平台缺的基础能力 |

详见 `docs/03-功能清单与改动说明.md` 和 `docs/11-小组与答辩意见改造记录.md`
